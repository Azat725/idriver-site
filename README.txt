Сайт автошколы iDriver

Откройте index.html в браузере. Сборка и установка зависимостей не нужны.
Стили, скрипты и анимации находятся в index.html. Мультяшные автомобили и шрифт загружаются из папки assets.
Интернет нужен только для переходов по внешним ссылкам и записи через WhatsApp.

Форма проверяет имя и телефон, затем открывает WhatsApp выбранного учебного класса с готовым сообщением.
В разделе «Контакты» можно скопировать адрес, если браузер разрешает доступ к буферу обмена.
Введённые данные не сохраняются и не отправляются сайтом самостоятельно.

Цены, программы и сведения об автошколе взяты с https://айдрайвер.рф/.
